# Windage Engine — the mark

| File | Use |
|---|---|
| `windage-engine.svg` | the mark in deep `#1B2027`, for light backgrounds |
| `windage-engine-display.svg` | the mark in display `#F2F4F7`, for dark backgrounds |
| `windage-engine-icon.svg` | the app icon, on Apple's 1024 grid |
| `favicon.svg` | a browser tab |
| `exports/` | PNGs of all of the above |

Every file here is generated from `EngineMark.outline` in `Sources/WindageEngine/EngineMark.swift`, and
`EngineMarkTests` fails if a file and the outline disagree.

## Crediting the engine

`SplashScreen` shows **Made with** · the mark · **Windage Engine**, which is the simplest way to credit it. In
running text the name is written **Windage Engine**, in title case. The mark has no color of its own, so it sits
inside any game's palette; use the deep version on light backgrounds and the display version on dark ones.
